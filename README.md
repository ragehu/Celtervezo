# K&H Céltervező prototípus

Egyszerű, statikus HTML-prototípus célösszeg és megtakarítási terv becsléséhez. Nincs buildlépés vagy külső függőség: GitHub Pagesen az `index.html` közvetlenül kiszolgálható.

## Indítás

Nyisd meg az `index.html` fájlt böngészőben, vagy engedélyezd a GitHub Pages szolgáltatást a repository `main` ágának gyökérkönyvtárára.

## Megjegyzés

Ez egy nem hivatalos koncepcióprototípus. A számítás nem feltételez hozamot; az eredmények nem személyre szabott pénzügyi vagy befektetési tanácsok. A termékfeltételeket mindig a K&H hivatalos oldalán ellenőrizd. A megadott adatok a böngészőben maradnak.
